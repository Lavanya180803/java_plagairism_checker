# java_plagairism_checker
This project implements a plagiarism checker for two text files, designed to detect similarities between their content and identify potential cases of copied or reused text. The program reads and analyzes the contents of both files, compares the text using string matching or similarity algorithms, and outputs a similarity percentage.
The goal of this tool is to assist in checking the originality of written content in academic or professional settings, where verifying the uniqueness of a document is crucial. By analyzing word patterns, common phrases, or structural similarities, the plagiarism checker can highlight whether one file has content that closely matches the other.

Key Features:
•	Reads and processes two input text files
•	Cleans and tokenizes the content (e.g., removes punctuation, lowercases text)
•	Compares content using methods like word matching
•	Outputs a similarity score as a percentage
This simple yet effective tool is ideal for educational use, helping instructors and students detect unintentional plagiarism and promoting original writing practices.
